## Bit 8 (the converter never writes it): no effect on routing or targeting
OpenKore pinned commit edbd385 (`src/Field.pm:60-64`): TILE_NOWALK 0, WALK 1, SNIPE 2, WATER 4, CLIFF 8. Bit 8 is "cliff". It is read only by `Field::isCliff` (Field.pm:345), shown by `getCellInfo` (Field.pm:303) and drawn by the Win32 map viewer (`Interface/Win32/Map.pm:87-89`). Routing (`isWalkable`, `checkPathFree`, A*), line of sight and attack checks (`checkLOS`, `canAttack`) use masks TILE_WALK or TILE_WALK|TILE_SNIPE only. Nothing calls `isCliff` in AI, Route, CalcMapRoute or Misc. Losing bit 8 changes nothing in behaviour; it only removes a cosmetic info line. Not a finding. (rathena itself has no cliff cell type in the cache, so the cache cannot carry it anyway.)
