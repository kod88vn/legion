### Minor
1. The fixtures are not captured output and nothing regenerates them. They are right today (above), but the contract tests
   (`test_market.py:155-207`) only check that fixture keys are a subset of the Go struct keys, in one direction, with no
   types, and never check that the keys the page reads exist in the fixture. A renamed or new Go field would fail nothing.
   Recommend a committed Go test that writes the fixtures from the real handlers and fails on drift. I wrote it as a patch:
   `docs/reports/reviews/ea6b722972fc6eee34966aa53e070d7d5f84fd92-marketfixtures_test.patch` (adds
   `legion/marketfixtures_test.go`, `TestDashFixtures`). `UPDATE_DASH_FIXTURES=1 go test -run TestDashFixtures` rewrites
   market_engine, market_feed, kite_counters and kite_counters_core; a plain `go test` diffs key paths and types and fails
   on any difference (mutation: renaming `caps.per_item` in a fixture fails it). It compiles, is gofmt clean and runs in the
   scratch merge. Caveats: applied as is it fails on market_feed.json (the committed feed has an empty `zeny_per_hour`:
   regenerate once, and make test_market.py:306 assert a row); the farmer_orders writer is a commented stub until
   fix/farmer-orders is on main; `gocheck.sh` copies only `legion/*.go`, so the test skips there (it finds
   `../tests/dashboard/fixtures` in a checkout, `DASH_FIXTURES` overrides) unless gocheck also copies the fixtures.
2. No XSS test (a notice text or item name such as `<img onerror>` through the DOM test). The code is correct today; a
   test would keep it so.
3. `tools/system/crier.py` was stored with CRLF on main and is LF now: the diff shows 247+/234- while the real change is
   13 added lines (`git diff -w`). It hides the change in review and can conflict with other branches that touch the file.
   Prefer the original line endings.
4. `rules()` types `"default_mode": "dry"` as a literal (crier.py:146) instead of reading the default `send` uses; true
   today. `counters_since` can show the Go zero time (`0001-01-01...`) as text before the first counter load; harmless.
