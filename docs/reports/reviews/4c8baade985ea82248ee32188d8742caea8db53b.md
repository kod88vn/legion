## Answer to the main question: does a held member fight?
Yes for non-healers. With Goal.Map == own floor and her on another map, partyThink reaches
`!ok || lead.Map != b.MapName` (party.go:~711) and returns false. ai.go:626 then falls through to `b.hunt` (not
attackersOnly). stickRefs returns none (partystick.go:86, leader not here), so there is no leash. The PT32 filter
(pt32.go) applies, so it fights monsters in reach. With nothing in reach it ends in explore, state "roaming" (ai.go:~1897),
so it wanders the floor alone rather than standing idle. Healers: when healerStickOn is on, the healer skips the gate and
goes in to her (humanparty.go:365), so it is not held. With healerstick off a healer would run `attackersOnly` and only
fight back (idle on the floor); not live now. Not an idle-member bug. (Side note: roaming alone on a floor is its own
risk, but it is the round-1 design.)
