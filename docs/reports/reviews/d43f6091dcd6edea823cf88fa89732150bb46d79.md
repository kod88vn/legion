branch), so exp is `n/a` in the engine era. The core metrics of Constitution 3.2 are kills per minute and zeny per hour:

needed for them. The gap is reported honestly (n/a, not 0), so nothing misleads. File a bug: add a `base_exp`/exp-h field to
partyMemberView for every member (Go change, deploy agent), then read it here. Does not block this merge. Also note the
engine era's kills_5m is a delta against the previous snapshot, so it is None on the first round.
