# Gate register

A hard gate is a rule whose breach is unsafe, destructive, irreversible, or explicitly forbidden by the owner. Every
gate has an ID (G01 and up). The ID of every gate must appear in the always-loaded core (`RULES.md`);
`tools/system/gatecheck.py` fails if one is missing. Checked against the tree on 2026-11-14 (commit 63ca923).

Enforcement kinds: **hook** (Claude Code hook), **script** (a tool refuses), **engine** (Go code), **plugin**
(OpenKore plugin), **server** (rAthena config), **text only** (nobody and nothing stops a breach: candidate for code).
